# Food Ordering System

## Project Description
Food Ordering System is a Java-based desktop application developed using Object-Oriented Programming concepts. The system allows customers to view menu items, place food orders, and generate bills. It uses MySQL database for storing menu and order information.

## Project Purpose
The purpose of this project is to automate the food ordering process in restaurants. It helps users browse menu items, place orders, and calculate bills efficiently.

## Why This Project
We selected this project to apply OOP concepts in a real-world application. It demonstrates how software can simplify restaurant operations and improve order management.

## Main Modules

### 1. Customer Module
Handles customer information.

### 2. Menu Module
Displays available food items and prices.

### 3. Order Module
Allows users to place orders.

### 4. Billing Module
Calculates total bill and displays order summary.

### 5. Database Module
Connects the application to MySQL using JDBC.

## Folder Structure
- src/ : Contains all Java source files

- database.sql : SQL script to create database and tables

## How to Run the Project
1. Open the project in your Java IDE.
2. Add the MySQL Connector JAR from the `lib` folder to the project libraries.
3. Create the MySQL database and import `database.sql`.
4. Compile all Java files.
5. Run the main class (for example `Main.java`).
